1. Introduction to Python

Python is a high-level programming language that is simple, readable, and easy to learn. It is commonly used for web development, automation, data analysis, and artificial intelligence.

First Python Program

print("Hello, World!")

The print() function is used to display text or information on the screen.

Tip: Python uses indentation to organize blocks of code.

2. Variables

Variables are used to store information in a program. Python can store different types of data such as text and numbers. 

name = "Ralph"
age = 18

print(name)
print(age)

In this example, name stores text and age stores a number.

Try it: Change the name and age in the example and run the program.

3. Conditional Statements

Conditional statements allow a program to make decisions based on a condition. 

age = 18

if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

The if statement checks whether a condition is true. If the condition is false, the else statement runs.

Remember: Python uses a colon and indentation after an if or else statement.

4. Loops

Loops are used when you want to repeat a block of code.

For Loop Example

for i in range(5):
    print(i)

This program prints the numbers from 0 to 4.

Another Example

for i in range(1, 6):
    print("Python", i)

This example repeats the statement five times.
